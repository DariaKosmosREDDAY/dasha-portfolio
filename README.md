# Дарья Чемагина — портфолио

Первая версия: один адаптивный экран, крупная типографика и исходный портрет без кадрирования. Светлый и тёмный фон, просмотр фото по клику. Сайт работает без внешних сервисов и установки зависимостей.

## Самый простой способ открыть

Дважды нажмите на `index.html` в этой папке — страница откроется в браузере.

## Локальный сервер

В Терминале выполните:

```sh
cd /Users/dariach/Desktop/dasha.portfolio
npm run dev
```

Откройте **http://localhost:5173**. Для остановки сервера нажмите `Ctrl+C`. После редактирования файлов обновите страницу.

Если порт занят: `PORT=5174 npm run dev`, затем **http://localhost:5174**.

## Публикация на Vercel

`npm run build` копирует исходные HTML, CSS, JavaScript и фото без изменений в `dist/`. Настройки сборки находятся в `vercel.json`: тип проекта **Other**, команда **npm run build**, папка результата **dist**. Внешние зависимости не нужны.

После подключения GitHub-репозитория к проекту Vercel изменения в основной ветке `main` будут публиковаться автоматически.

## Файлы

- `index.html` — текст и структура первого экрана.
- `styles.css` — композиция, цвета и адаптация для мобильных экранов.
- `script.js` — смена фона и просмотр фото.
- `assets/daria-chemagina.jpeg` — точная копия приложенного фото.
- `server.mjs` — локальный сервер на Node.js 18+.
- `build.mjs` — подготовка статических файлов для публикации.
- `vercel.json` — настройки публикации на Vercel.
